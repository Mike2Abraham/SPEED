Descargas para Windows

¿Qué son "Parches" y cuáles son las "Versiones normales"?

Te explicamos en palabras simples para evitar confusiones:

Archivos "Parches" (actualizaciones):

Son pequeñas actualizaciones que corrigen fallos o añaden mejoras. No contienen todos los archivos necesarios para ejecutar la aplicación por sí solos.

Por eso primero debes instalar la versión completa (una descarga normal) o tener una versión anterior que no sea parche. Luego aplicas el parche encima para actualizar.

Versiones normales (programa completo):

Son paquetes completos del programa. Si descargas una versión normal la instalas y estará funcionando sin necesidad de otra descarga.

Resumen: Descarga siempre primero una versión normal (completa). Los parches sirven sólo para actualizar esa instalación.
